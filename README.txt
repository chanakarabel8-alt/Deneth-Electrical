DENETH ELECTRICAL - FREE WEBSITE
1. Sign in/create account at https://github.com
2. Create a PUBLIC repository named deneth-electrical.
3. Upload index.html to the repository root.
4. Open Settings > Pages.
5. Under Build and deployment choose Deploy from a branch; select main and /(root), then Save.
6. Wait for the website URL to appear in Settings > Pages.
Free URL format: https://YOUR-USERNAME.github.io/deneth-electrical/
A custom domain such as denethelectrical.com must be purchased separately and connected in Pages settings.
